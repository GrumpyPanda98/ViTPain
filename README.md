# ViTPain EEG Data Analysis Project

## Project Structure

- `preprocessing/`: Contains scripts for preprocessing EEG data.
- `loader.py`: Script for loading EEG data from MATLAB file format.
- `README.md`: Project README file.
- `python3.11_packages.txt`: List of Python packages and their versions used in the project.

## Preprocessing

- `preprocessing_script.py`: Script for preprocessing EEG data.
- `utils.py`: Utility functions for data preprocessing.

## Vision Transformer (ViT)

- `vit_model.py`: PyTorch implementation of a Vision Transformer model.
- `train_vit.py`: Script for training the Vision Transformer on EEG data.
